# Yahoo! 乗換案内 检索 URL 参数

基础地址：`https://transit.yahoo.co.jp/search/result`

所有参数值需 URL 编码（UTF-8 百分号编码）。以下参数集与 app 内 `TransitService.buildUrl` 完全一致：

| 参数 | 说明 | 示例 / 取值 |
| --- | --- | --- |
| `from` | 出发地名称（与 `flatlon` 二选一或同时给） | `京都` |
| `to` | 目的地名称 | `東京` |
| `fromgid` / `togid` | Yahoo 地点 gid（用名称/坐标检索时留空） | 空 |
| `flatlon` | 出发地坐标，**格式 `lat,lng,`（注意尾逗号）** | `35.011639,135.768028,` |
| `tlatlon` | 目的地坐标，同上 | `35.681236,139.767125,` |
| `via` / `viacode` | 途经地（不用时留空） | 空 |
| `y` | 年 | `2026` |
| `m` / `d` | 月 / 日（两位补零） | `09` / `03` |
| `hh` | 小时（两位补零） | `10` |
| `m1` / `m2` | **分钟的十位 / 个位**（Yahoo 拆成两个参数） | 10:37 → `m1=3&m2=7` |
| `type` | `1`=按出发时间检索，`4`=按到达时间检索 | `1` |
| `ticket` | 票价类型：`ic`=IC卡，`normal`=现金 | `ic` |
| `expkind` | 含特急料金（固定 `1`） | `1` |
| `userpass` | 含用户手机月费（固定 `0`） | `0` |
| `ws` | 步行速度 1-5，越大越少步行 | `3` |
| `s` | 排序：`0`=时间最短，`1`=换乘最少，`2`=票价最低 | `0` |
| `al` | 固定 `1` | `1` |
| `shin` | 是否包含新干线：`1`/`0` | `1` |
| `ex` | 是否包含特急：`1`/`0` | `1` |
| `hb` | 是否包含急行/快速：`1`/`0` | `1` |
| `lb` | 是否包含普通/各站停车：`1`/`0` | `1` |
| `sr` | 是否包含私铁/其他：`1`/`0` | `1` |

## 示例

2026-09-03 10:37 从京都到东京，IC 优先、时间最短：

```
https://transit.yahoo.co.jp/search/result?from=%E4%BA%AC%E9%83%BD&to=%E6%9D%B1%E4%BA%AC&fromgid=&togid=&via=&viacode=&y=2026&m=09&d=03&hh=10&m1=3&m2=7&type=1&ticket=ic&expkind=1&userpass=0&ws=3&s=0&al=1&shin=1&ex=1&hb=1&lb=1&sr=1
```

提示：脚本 `yahoo_transit.py --url-only --from 京都 --to 東京 ...` 会按同样规则生成 URL，比手工拼接更不容易出错。
